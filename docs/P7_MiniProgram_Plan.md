# 《墨江湖》P7 微信小程序上架方案（第一章版本）

> 配套文档：设计定稿见 `docs/GDD.md` §13；开发规划见 `docs/Chapter1_DevPlan.md`。
> 本方案为第一章（序章+下山+拜师，20~25 分钟可玩版本）上架微信小程序的执行规划。

## 0. 目标与验收

- **目标**：第一章完整可玩版本在微信小程序上线，浏览器/小程序画面一致（触屏层默认显示，方案 A 已落地）
- **验收标准**：
  1. 微信开发者工具可打开工程并真机预览（序章全流程可玩）
  2. 主流机型（iPhone 8 / 安卓千元机）30fps 流畅
  3. 横屏 + 安全区适配，无元素被刘海/底部横条遮挡
  4. 存档正常（localStorage → wx 存储自动映射）
  5. 上传体验版 → 提审 → 通过发布

## 1. 前置确认（已探测/待确认）

| 项 | 状态 |
|---|---|
| 微信开发者工具 CLI | ✅ `D:\微信web开发者工具\cli.bat`（open / preview / upload 均可调用） |
| AppID | ⏳ 待确认：正式小程序 AppID 或测试号 `touristappid`（构建 wechatgame 时需要） |
| 触屏输入 | ✅ TouchControls 默认显示（摇杆 + 交互/背包/图鉴/任务/宗门/退出按钮），真机 touch + PC mouse 双输入 |
| 存档系统 | ✅ SaveSystem 多档位 + localStorage，微信环境自动映射 `wx.setStorageSync`，零改动 |
| 包体 | ✅ 纯程序化绘制无外部资源，预估 <1MB（主包 2MB 限制无忧） |
| 引擎 | ✅ Cocos Creator 3.8.8 内置 `wechatgame` 构建目标，官方维护 |

## 2. 阶段划分与任务清单

### P7.1 构建接入（0.5~1 天）★ 第一步

| 任务 | 说明 |
|---|---|
| 添加 wechatgame 平台 | 项目设置 → 构建发布 → 平台选择「微信小游戏」（首次需在项目配置启用） |
| 构建参数 | 主包模式（无远程分包）；AppID 填入正式号或测试号 |
| CLI 打开 | `D:\微信web开发者工具\cli.bat open --project build\wechatgame` |
| 真机预览 | `cli.bat preview --project build\wechatgame --qr-output qr.png` → 手机扫码 |
| 验收 | 序章三幕在小程序环境全流程可玩，无白屏/报错/加载失败 |

**风险与对策**：
- 构建报错（Canvas/Graphics 兼容）：微信小游戏支持 WebGL，Cocos 渲染链路兼容，若个别 API 不兼容按报错逐项修复
- 首包加载慢：主包 <1MB 无需分包；若超限再拆首场景分包

### P7.2 布局适配（0.5~1 天）

| 任务 | 说明 |
|---|---|
| 横屏锁定 | `game.json` 设 `"deviceOrientation": "landscape"` + 项目 screenOrientation 一致，防止竖屏玩 |
| 安全区适配 | 读取 `wx.getSystemInfoSync().safeArea`，UI 关键元素（HUD 四角、触屏按钮、面板）避让刘海/底部横条 |
| 机型宽高比 | 设计 1280×720（16:9），SHOW_ALL 在 19.5:9 / 折叠屏会有黑边：评估是否接受黑边（水墨风可接受）或 UI 层拉伸策略 |
| 触屏层微调 | 摇杆/按钮避开安全区（当前位置 -400/-240 与右侧 x470 已留余量，真机验证后微调） |
| 验收 | 主流机型（iPhone 12/13/14、小米、华为、折叠屏）画面完整无遮挡，横屏强制生效 |

### P7.3 性能优化（1~1.5 天）★ 最大工作量

| 项 | 现状 | 对策 |
|---|---|---|
| GroundPainter 逐帧重绘 | 每帧 Graphics 清空重画 | **区域切换时绘制一次并缓存**（离屏 RenderTexture 或静态化节点），帧内不重绘 |
| InkBackground 视差层 | 每帧随镜头重绘 | 改为静态图块/降低重绘频率（仅在镜头移动超阈值时重绘） |
| Stickman 关节动画 | Graphics 重绘 | 保留（角色数少），可降低重绘频率或仅姿态变化时重绘 |
| 帧率目标 | 60fps 桌面 | 小程序目标 30fps（中端机），用 `wx.setPreferredFramesPerSecond(30)` 或引擎适配 |

**验证工具**：微信开发者工具「性能」面板 + 真机 Profile（`wx.getPerformance()` 采样），对比优化前后帧耗时。

**验收**：iPhone 8 / 安卓千元机 30fps 稳定，战斗/爬塔无卡顿。

### P7.4 平台能力（0.5~1 天，可选但建议）

| 功能 | 说明 |
|---|---|
| 云存档 | `wx.cloud` 云开发：存档上传/拉取，换机不丢档（SaveSystem 增加云同步层，本地为主、云端备份） |
| 分享 | `wx.shareAppMessage`：过关/拜师时引导分享，裂变入口 |
| 游戏圈 | `wx.createGameClubButton` 常驻入口 |
| 激励视频（可选） | 战斗失败复活/双倍经验，注意审核政策（小游戏广告需资质） |

**注意**：若做登录/云存档，需在微信后台配置**用户隐私保护指引**（收集 openid 声明），否则审核被拒。

### P7.5 提审发布（0.5 天）

| 任务 | 说明 |
|---|---|
| 内容合规检查 | 武侠/江湖题材无敏感内容；确认无真实货币/金融元素；纯单机无内购（个人主体无虚拟支付限制，本作不受影响） |
| 类目选择 | 游戏类目（若需版号提示：**个人主体小游戏可免版号上线**，但无虚拟支付——本作单机无需支付，无影响） |
| 隐私协议 | 若启用 P7.4 登录/云存档需配置隐私指引；不启用则无需 |
| 上传体验版 | `cli.bat upload --project build\wechatgame --version 1.0.0 --desc "第一章完整版"` |
| 提审 | 微信公众平台提交审核（需已注册小程序账号 + AppID） |
| 验收 | 审核通过、线上可玩、存档/触屏正常 |

## 3. 工作量汇总

| 阶段 | 工时 | 依赖 |
|---|---|---|
| P7.1 构建接入 | 0.5~1 天 | AppID |
| P7.2 布局适配 | 0.5~1 天 | P7.1（真机看效果） |
| P7.3 性能优化 | 1~1.5 天 | P7.1（真机测量基线） |
| P7.4 平台能力 | 0.5~1 天 | 可选 |
| P7.5 提审发布 | 0.5 天 | P7.1~7.4 |

**建议执行顺序**：P7.1（立即做，验证可行性）→ P7.3 性能基线（真机测）→ P7.2 布局 → P7.4 → P7.5。

## 4. 风险与对策总表

| 风险 | 概率 | 对策 |
|---|---|---|
| Cocos 构建 wechatgame 报错 | 低 | 按报错逐项修（渲染/音频 API 均有官方适配层） |
| 中低端机卡顿（Graphics 重绘） | 中 | P7.3 缓存策略（绘制一次+静态化） |
| 横屏被手机强制竖屏 | 低 | game.json 横屏声明 + 真机验证 |
| 安全区遮挡 UI | 中 | safeArea 读取 + 边距避让，真机多机型验证 |
| 审核被拒（隐私/类目） | 中 | 提前配置隐私指引；单机无支付规避支付资质 |
| 云存档被拒（若做） | 低 | 后台配置收集声明即可 |
