# 《墨江湖》MoJiang — 修仙水墨风火柴人小游戏设计文档 (GDD)

版本：v0.1 ｜ 引擎：Cocos Creator 3.8.8 ｜ 平台：PC 桌面（可移植微信小游戏）｜ 状态：核心循环原型

---

## 0. 一句话概述

一款水墨宣纸风格的平面古风小游戏：玩家扮演修仙火柴人，通过挑战 NPC 与爬塔获取武学（内功/轻功/武功）、更换武器（剑/弓/琴/刀/枪），自由搭配武学组合，在即时战斗中验证实力，逐步成长。

设计灵感：**暴走英雄坛**的平面古风漫画稿风格 + 极简火柴人表现 + 修仙题材。

---

## 1. 风格规范（视觉）

### 1.1 基础风格：平面古风漫画稿 + 水墨
- 底色：宣纸米白（#F5EFE2），所有内容像"画在纸上"。
- 线条：墨色（#2B2B2B）粗笔触线条，边缘可带毛笔顿挫感。
- 填充：淡墨色阶（#4A4A4A、#6E6E6E、#9A9A9A），不用写实贴图。
- 元素优先级：能用平面火柴人解决的，一律火柴人解决（角色、NPC、怪物）。

### 1.2 火柴人规范
- 头：墨点/小圆（有神态可加简单表情：眯眯眼、怒眉）。
- 躯干与四肢：单线/双线笔触，关节处墨点。
- 武器：贴合手部的单线勾勒（剑=细长刃+护手；弓=弧+弦；琴=矩形+弦纹；刀=弯刃；枪=长杆+尖头）。
- 动画：程序化骨骼（头/躯干/四肢/武器节点旋转+位移），不依赖序列帧美术。
- 水墨特效：墨渍爆开（随机斑点缩放）、剑气弧线、刀光扫线、音波圆环——全部 Graphics 程序化绘制。

### 1.3 场景
- 主城：水墨山村/门派场景（远山、树、屋舍剪影 + 淡淡云雾），NPC 散布。
- 爬塔：每层一张"擂台"构图，背景随层数变深（墨色加重）。

## 2. 核心循环（Core Loop）

```
出生（基础武学+武器）
   ↓
主城探索（轻功跑动）
   ↓
找地图NPC 切磋 ──胜──► 获得 修为 + 武学残页/武器
   ↓                            │
变强：学新武学（三槽自由搭配）◄──┘
换武器（剑弓琴刀枪）
   ↓
爬塔挑战（20层）──► 层数奖励：修为/武学/武器
   ↓
验证实力 → 解锁更强 NPC → 循环
```

成长货币：**修为**（经验）→ 升级 → 属性成长；**武学残页** → 解锁武学；**武器**由 NPC 赠送/塔层掉落。

## 5. 属性与成长

### 5.1 属性一览
| 属性 | 来源 |
|---|---|
| 气血 HP | 等级、内功 |
| 内力 MP | 等级、内功 |
| 攻击 ATK | 等级、武器、武功、内功 |
| 防御 DEF | 等级、内功 |
| 移速 SPD | 基础 220px/s、轻功 |
| 攻速 ATK SPD | 武器、轻功（影响普攻前摇） |
| 闪避 DGE | 轻功、内功（概率闪避全额伤害） |
| 暴击 CRT | 内功（1.5 倍伤害） |

### 5.2 等级公式（等级 1~30，境界随等级变化）
- 境界：1-5 炼气｜6-10 筑基｜11-15 金丹｜16-20 元婴｜21-25 化神｜26-30 大乘
- HP = 100 + 等级×15 + 内功气血加成
- MP = 50 + 等级×5 + 内功内力加成
- ATK = 5 + 等级×2 + 武器攻击 + 内功攻击加成
- DEF = 1 + 等级 + 内功防御加成
- 升级所需修为 = 等级 × 20

### 5.3 伤害公式
```
命中判定：随机 < (1 - 目标闪避) 则命中，否则闪避（飘"闪"字）
基础伤害 = max(1, ATK × 招式倍率 − 目标DEF × 0.5)
浮动 = 0.9 ~ 1.1 随机
暴击 = 1.5 倍（显示墨红大字）
最终伤害 = 基础伤害 × 浮动 × 暴击系数
```

## 6. 战斗系统（即时战斗）

- 视角：2D 平面，战斗在地图原地触发（切磋）/塔内擂台触发。
- 操作：WASD 移动；J/左键 普攻；K/空格 冲刺（有轻功时）；1/2/3 武功；Esc 暂停。
- 轻功联动：移速影响走位；攻速影响普攻前摇；闪避概率生效；冲刺为位移技能。
- 内力回复：基础 2/s + 内功加成；武功消耗内力。
- 胜负：气血归零。切磋可主动认输（认输无惩罚，但无奖励）。
- 掉落：获胜得修为（NPC等级×10 + 塔层×5）；残页/武器按 NPC/层数表。

### 7.2 问道塔（20 层）
- 每层一个守卫，属性 = 基础 × (1 + 0.08×层)。
- 每 5 层精英（掉武学残页），10/15/20 层 Boss（掉武器/高阶内功轻功）。
- 塔内不可逃跑，可死亡重来；记录最高层数。
- 难度曲线：前 5 层适合 Lv3，前 10 层适合 Lv8，前 15 层适合 Lv14，20 层适合 Lv20+。

## 9. 项目架构（Cocos Creator 3.8.8）

```
MoJiang/
├── assets/
│   ├── scenes/Main.scene            # 主场景（入口）
│   ├── scripts/
│   │   ├── core/                    # GameManager(单例)/EventBus/SaveSystem
│   │   ├── data/                    # 配置表：MartialArts/Weapons/Npcs/Tower
│   │   ├── combat/                  # Fighter/CombatManager/DamageFormula/SkillSystem
│   │   ├── actors/                  # Stickman(火柴人渲染)/PlayerController/NpcActor
│   │   ├── art/                     # InkBackground(水墨背景)/InkEffects(墨特效)
│   │   ├── ui/                      # HUD/MartialPanel/WeaponPanel/NpcDialog/TowerPanel
│   │   └── tower/                   # TowerManager
├── docs/GDD.md
├── package.json
├── tsconfig.json
└── settings/
```

### 9.1 关键设计决策
- **全部美术程序化**：火柴人、水墨背景、特效均用 cc.Graphics 代码绘制 → 零美术资源依赖，迭代最快，风格统一。
- **配置驱动**：武学/武器/NPC/塔层全走数据表，改数值不改代码。
- **单场景架构**：主城/塔/战斗都放同一场景的不同层管理，减少场景切换开销，利于小游戏移植。
- **面向扩展**：战斗胜负判定、NPC 状态机预留人机（AI 玩家）接口。

### 12.8 战斗系统现状（第三轮后：回合制改造）
- 独立战斗界面（BattleArena）：全屏墨色擂台 + 双方血条/内力 + 回合信息 + 指令面板

- 敌人 AI（EnemyAI）：技能优先、血少防御、普攻兜底
- 玩家操作：大世界 WASD 移动 / E 交互 / B 背包；战斗中点按钮行动
